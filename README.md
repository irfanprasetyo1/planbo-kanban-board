# Planbo - Kanban Board

Aplikasi Kanban Board sederhana untuk mengatur tugas dengan sistem kolom (To Do, In Progress, Done) yang bisa dipindah lewat drag-and-drop.

> **Status: Masih dalam pengembangan.** Ini adalah project portofolio saya sebagai Front-End Developer, dan saya akan terus melanjutkan perkembangannya.

## Fitur

- Drag-and-drop kartu antar kolom (mouse)
- Dark mode / light mode toggle
- Data tersimpan otomatis lewat localStorage
- HTML semantic dan atribut aksesibilitas

## Dibangun dengan

- **HTML5** — struktur semantik
- **CSS3** — custom properties (variables), dark mode
- **JavaScript (Vanilla)** — modular, Drag and Drop API native
